## 1. Тренды контента 2026: О чем записывать?
Общие темы перенасыщены. Мы рекомендуем фокусироваться на узких нишах, где ваша экспертиза будет уникальной:
* **Микро-экспертность:** Вместо «маркетинга» — «маркетинг для локальных производств».
* **Образовательные циклы:** Пошаговые инструкции и разбор сложных кейсов в аудиоформате.
* **Видеоподкасты:** Сочетание глубокого смысла и качественной визуальной картинки 4K.

## 2. Разработка сценария и структуры
Качественная запись невозможна без предварительной подготовки. В Студии 105 мы выделяем три уровня сценария:
1. **Пунктирный план:** Список ключевых тезисов для сохранения динамики живого разговора.
2. **Скрипт под телесуфлер:** Дословный текст для экспертных монологов и лекций.
3. **Таймлайн-сетка:** Распределение выпуска по рубрикам (интро, блок новостей, интервью, блиц).
